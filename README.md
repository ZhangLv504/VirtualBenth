# VirtualBench
虚拟测试设备+上位机联调系统

## 项目定位

本项目旨在模拟经典工控/半导体设备软件的架构形态，并探索边缘计算（Edge AI）在工业场景中的落地。具体包含以下三个核心层面：

1. **经典上下位机架构模拟**
   * **下位机（设备端）**：模拟真实硬件设备的数据采集与状态上报。
   * **上位机（软件端）**：模拟工业控制软件的界面展示、指令下发与逻辑调度。

2. **ONNX 端侧推理集成**
   * 在上位机或边缘网关集成 ONNX Runtime，实现 AI 模型的本地化、低延迟推理，摆脱对云端算力的强依赖。

3. **数据闭环验证**
   * 构建完整的数据流通道：**设备数据流**（输入） → **AI 检测**（处理） → **告警展示**（输出），验证端到端的业务可行性。





> **⚠️ 注意：** 由于模型文件体积较大，未包含在 Git 仓库中。请自行下载模型文件（如 `xxx.onnx`），并放置于项目根目录的 `models/` 文件夹下。
